# Onboarding Prompts

这些示例用于测试或演示 CCC。CCC 是 Career Cognition Compass 的缩写。这些示例故意保留一点混乱感，因为这个 Skill 的重点就是从“不知道怎么说”开始整理。

## 混乱开局

```text
Use $career-cognition-compass.

我不知道自己应该找什么工作。之前有一段 Gap，做过一些运营相关的事情，也自学过一点 AI 工具，但刷小红书和 LinkedIn 越看越焦虑。请先帮我整理我已经有什么信息、还缺什么，以及下一步该做什么。
```

## 语音转文字长文本

```text
Use $career-cognition-compass.

下面是我对着手机录音后转出来的文字，内容比较乱，可能有重复和口语。我已经把公司、城市和数据脱敏了。请先帮我整理当前状态、经历证据、可迁移能力、可能方向、硬技能缺口和下一步行动。

[粘贴录音转文字]
```

## 长期 Gap

```text
Use $career-cognition-compass.

我 Gap 超过一年了，现在想重新找工作，但不知道怎么解释，也不知道还能投什么岗位。请先帮我判断当前阶段、可迁移能力和最小行动，不要一开始就让我准备很多材料。
```

## 情绪波动与低能量启动

```text
Use $career-cognition-compass.

我已经很久没有稳定工作了，最近状态波动很大。每天都觉得应该找工作，但又不知道从哪一步开始，越刷社交媒体越焦虑。请不要给鸡汤或大计划，只帮我做焦虑降噪，并判断今天能做的 1 个很小的动作。
```

## 兼职/过渡工作

```text
Use $career-cognition-compass.

我可能需要先找兼职或临时工作过渡一下，但我担心兼职会消耗太多精力，影响正式求职。请帮我判断我适合找什么类型的兼职、哪些兼职应该排除，以及本周可以做的 1-3 个动作。
```

## 转行/转岗

```text
Use $career-cognition-compass.

我之前所在行业下行，想转行或转岗，但不知道自己的技能能迁移到哪里。请帮我把经历拆成证据和能力，给出 1-3 个可以先验证的方向，并告诉我还需要补什么证据。
```

## 项目经历盘点与深挖

```text
Use $career-project-experience-miner.

我做过一些项目，但说不清楚它们有什么价值，也不知道哪些能写进简历或作品集。请先帮我做项目总表，再选 1 个项目深挖成事实卡，先不要急着写简历。
```

```text
Use $career-project-experience-miner.

我搭过一个 Shopify 网站，但没有销售数据，后来也暂停了。我不知道这算不算项目。请帮我还原这个项目：我到底做过什么、能证明什么、不能夸大什么。
```

```text
Use $career-project-experience-miner.

我想把做过的项目整理成作品集，但现在每个项目都只有一个名字。请先判断每个项目是 DISCOVERED、PARTIALLY_MAPPED 还是 EVIDENCE_READY；没有到 EVIDENCE_READY 的项目先不要写作品集案例。
```

```text
Use $career-project-experience-miner.

我有一个个人 Skill 项目，没有用户量和商业结果，但有仓库、文档、demo 和版本记录。请判断它是否可以达到 EVIDENCE_READY；如果还不够，请告诉我缺哪些事实，不要要求我编不存在的数据。
```

## 职业族群筛选

```text
Use $career-cognition-compass.

我现在完全不知道该看什么岗位。运营、销售/BD、产品/项目、数据、市场、设计、职能支持、技术入门、AI 应用这些方向我都分不清。请先不要给我一长串岗位，帮我根据已有经历筛出最多 3 个角色族群，并说明每个方向的证据、缺口和 7 天验证动作。
```

## 快速就业

```text
Use $career-cognition-compass.

我现在更需要尽快找到工作。每天大概能花 2 小时求职。请帮我选择更实际的方向，做一个不超过 14 天的计划，只输出我真的会用到的材料。
```

## 投递后空档期

```text
Use $job-search-plan-review.

我这几天投完一批简历了，还没有面试消息。现在空档期不知道该做什么，总想刷新招聘软件。请帮我复盘投递质量、整理 JD 共性，并安排今天 5-20 分钟能做的一件事。
```

## 面试邀约信号画像

```text
Use $job-search-plan-review.

我最近两周投了 40 个岗位。A 简历投了 20 个用户运营 / 运营执行，收到 3 个邀约；B 简历投了 10 个产品助理，收到 1 个邀约；C 简历投了 10 个 AI Agent 工程师和高级产品经理，收到 0 个邀约。另有 1 个项目执行邀约来自朋友内推，不在这 40 个冷投里。请帮我做面试邀约信号画像，判断下一批怎么小规模验证。
```

## 面试表达结构

```text
Use $interview-review-miner.

我面试时回答很细，越说越多，面试官抓不到重点。问到“如果用户增长突然下降怎么办”时，我只会顺着一个原因讲。请帮我根据 JD 卖点改成更清晰的回答结构，最好也适合英文面试。
```

## 自我介绍框架

```text
Use $jd-company-prep.

我要准备产品运营岗面试的自我介绍和“为什么适合这个岗位”的回答。我不想要逐字稿，怕背不下来。我之前做过内容运营、用户调研和 AI 工具项目，请帮我抽象能力和回答框架。
```

## 面试反问问题

```text
Use $jd-company-prep.

我明天面产品运营岗，最后如果面试官问我有什么想问的，我应该反问什么？我不想问太大的问题。
```

## 英文面试语气校准

```text
Use $jd-company-prep.

这个岗位要求英文沟通，我想准备英文自我介绍和面试回答。我的英语能工作沟通但不是母语，之前做过运营和 AI 工具项目。请帮我准备，别写得太夸张，也别太生硬。
```

## Token 节省模式

```text
Use $career-cognition-compass.

我担心 token 太多，之后我会贴 JD、候选人背景卡、项目事实卡和中性主简历。请用最省 token 的方式帮我改简历和准备面试：复用已有卡片，只输出本轮新增、差异补丁、替换段落和下一步，不要每次重写所有内容。
```

## 近期工作行为定位

```text
Use $career-direction-clarifier.

我最近一段时间最常做的是梳理流程、写 SOP、拆需求、把别人说不清的东西整理成清单。我发现自己挺愿意做这类工作，但不是兴趣爱好。我想知道这说明我应该怎么定位。
```

## 发散收束

```text
Use $career-cognition-compass.

我现在想投运营、产品助理、数据分析、AI Agent，也想学 SQL、Python、剪辑、作品集，还要改简历、准备面试、做小红书账号。我越想越多，不知道先做哪个。请先帮我收束，不要把所有分支都展开。
```

## 校招新人

```text
Use $career-cognition-compass.

我是应届生，有课程项目、一段实习、两个比赛/获奖经历，但不知道怎么和岗位联系起来。请帮我整理求职证据，判断可以优先尝试哪些岗位。
```

## 在职换工作

```text
Use $career-cognition-compass.

我现在在职，想换工作，但不确定是换公司、换岗位，还是换行业。我也担心求职信息泄露。请先帮我澄清真正想改变的部分，并给一个低风险的准备顺序。
```

## 在职焦虑 / 工作疲惫

```text
Use $career-cognition-compass.

我现在还在职，但最近工作让我很焦虑、很累，下班后也恢复不过来。我还没想清楚自己是需要休息、调整边界、换工作，还是干脆离职。请不要直接劝我辞职，先帮我做在职焦虑/疲惫应对卡，拆出压力来源、今天能做的小动作，以及下一步是否需要进入离职/裸辞判断。
```

## 在职离职 / 裸辞犹豫

```text
Use $career-cognition-compass.

我现在在职，但已经很想离职，甚至想裸辞。可是我没有 offer，也不确定自己是需要休息、换公司、换岗位，还是整个方向都不对。请不要直接劝我辞或不辞，先帮我做离职/裸辞判断卡，评估现金流、现职损耗、市场验证、法律/合同风险和 7-14 天内可以做的验证动作。
```

## 缩写歧义

```text
Use $career-cognition-compass.

我说 SP 的时候指的是 SAS Programmer。我也在考虑 PM，但我不确定自己说的是产品经理还是项目经理。请先帮我建立一个小术语表，再比较这些方向需要的技能和证据。
```

## MBTI / 星座 / 性格标签

```text
Use $career-cognition-compass.

我是 INFP，也会参考星座来理解自己。我不想让这些标签直接决定职业方向，但我觉得它们能说明我对工作氛围、压力和协作方式的感受。请帮我把这些标签转成可验证的工作偏好、需要避开的环境和下一步要补充的真实例子。
```

## 目标公司准备

```text
Use $career-cognition-compass.

我想准备某一家公司的某个岗位。我会贴 JD。请不要直接生成套话，先帮我判断这个岗位重视什么、我有哪些匹配证据、最大的缺口是什么，以及面试前 1-3 个最该准备的问题。
```

## 使用环境分流

```text
Use $career-cognition-compass.

我想把这个求职流程放到不同 AI 工具里用：国内大模型、海外大模型、普通 LLM 对话、WorkBuddy、还有 Codex 这种文件代理。请帮我严格区分每种环境适合做什么、不适合做什么、需要用户提供什么，以及隐私边界。
```

## 面试复盘

```text
Use $career-cognition-compass.

我刚面试完，只记得几个关键词：留存、SQL join、用户分层、dashboard，不记得完整问题。请帮我还原可能的题型，整理进我的知识库，并准备 1-2 个高概率问题的回答思路。
```

```text
Use $interview-review-miner.

我刚面试完，面试官反馈说我 B 端经验不足。我只记得被问到用户分层、需求优先级、数据看板。请帮我判断这条反馈可能说明什么、简历哪里要改、下次面试要准备什么，以及后续投 JD 要注意什么。
```

```text
Use $interview-review-miner.

最近几次面试都被提到行业经验不足，但岗位不完全一样：一个是 B 端产品，一个是 AI 产品助理，一个是项目执行。请帮我判断这是不是重复反馈模式，哪些内容只影响某个 JD，哪些需要进入主简历或投递方向调整。
```

```text
Use $interview-review-miner.

这是我上一轮的候选人面试资料卡。下一轮是业务负责人面试，请帮我判断这轮应该继承哪些证据，哪些不足不要继续带入，并输出 candidate_interview_profile_patch 和 1-3 个面试前补强动作。
```

```text
HR 转述说我业务经验不足，但没有解释具体原因。请帮我先判断这条反馈的可信度和动作等级，不要直接改我的主简历。
```

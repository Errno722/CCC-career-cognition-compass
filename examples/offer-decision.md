# Scenario: Offer Decision

## User

```text
我有两个 Offer。
A 薪资高一点，但通勤远，岗位比较执行。
B 薪资低一点，平台小，但能接触更多产品和业务。
我不知道怎么选，也不知道能不能谈条件。
```

## What CCC Should Notice

- 不能用机械总分替用户做决定。
- 需要先拆硬性限制、重大风险、可权衡项和关键未知项。
- 薪资要区分固定收入、有条件收入和不确定收入。
- 谈条件只能基于真实 Offer 条件、职责范围、deadline 和用户优先级。

## Example Response

```text
先不打总分，也不直接替你选。

硬性限制：
- 通勤是否会影响长期稳定性？
- 薪资差距是否影响现金流底线？
- 两个 Offer 的 deadline 是否冲突？

重大风险：
- A 是否只有执行，没有成长空间？
- B 的平台和管理稳定性是否足够？

关键未知项：
- 试用期薪资和转正条件
- 绩效 / 奖金是否写入书面 Offer
- 直属上级和前 3 个月期待
- 是否有谈通勤、到岗时间或职责边界的空间

下一步：
先向两边各确认 2 个会改变你选择的问题，再决定是否谈条件。
```

## Why This Matters

Offer 决策不是“哪个看起来更好”，而是确认哪些条件会真正改变用户的生活、风险和下一轮职业筛选标准。

# See CCC in 60 Seconds

Synthetic example. No real personal data, employer data, or job-search material is used.

## 1. User Sends A Messy Situation

```text
I'm based in the US and applying for Product Operations roles.
I've changed my resume several times and had a few interviews,
but I'm not sure whether the problem is targeting, evidence, or interview answers.
```

## 2. CCC Picks One Main Thread

```text
Main thread:
Check whether the repeated friction is coming from targeting, evidence, or interview answers.

Parked:
- rewrite the full resume
- prepare a large interview question bank
- compare unrelated role families

Next step:
List the last 3 roles you applied to and what happened after each application.
```

## 3. User Adds One Project Or Role Detail

```text
Most roles ask for cross-functional coordination, process improvement,
and product operations metrics. My strongest example is a workflow cleanup project.
```

## 4. CCC Separates Facts From Assumptions

```text
Confirmed facts:
- target role family: Product Operations
- repeated requirement: coordination + process + metrics
- strongest evidence: workflow cleanup project

Assumptions to verify:
- whether the project has measurable impact
- whether your role was owner, contributor, or coordinator
- whether interview answers explain your judgment, not just your tasks
```

## 5. User Shares A JD

```text
The JD asks for stakeholder coordination, process documentation,
launch support, dashboard usage, and post-launch review.
```

## 6. CCC Gives A Small Patch And One Next Action

```text
Resume patch:
- Keep Product Operations as the main role family.
- Add one evidence line for workflow cleanup.
- Do not rewrite the full resume yet.

Interview prep:
Use the workflow project to explain:
1. what was unclear before;
2. how you diagnosed the bottleneck;
3. what changed after the process update.

Next action:
Write the workflow project in 5 bullets: context, your role, action, result, evidence gap.
```

# CCC Local Web App

这是 CCC 的本地静态 Web 应用版本。它不接入 API，不上传数据，主要用于把混乱输入整理成可复制给 LLM / Agent 的任务包。

## 使用方式

直接用浏览器打开：

```text
webapp/index.html
```

也可以在本地启动一个静态服务：

```bash
cd webapp
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 适合做什么

- 粘贴语音转文字、碎片经历、JD、面试回忆或简历片段；
- 本地判断当前任务更像方向澄清、项目挖掘、职业定位、简历材料、JD 分析、面试复盘或行动计划；
- 检测是否可能需要先做项目总表、单项目事实卡、个人贡献边界和证据缺口；
- 标记项目状态：`DISCOVERED`、`PARTIALLY_MAPPED`、`EVIDENCE_READY`，提醒只有事实足够完整时才进入材料表达；
- 支持生成临时草稿模式提示：赶投递时可以用保守表达，但必须暴露未知字段和不能夸大的内容；
- 检测是否可能需要职业定位 / 候选人叙事重建；
- 检测是否可能需要面试关键词复盘、面试官反馈卡、反馈可信度判断、重复反馈统计、下次面试回答卡，以及简历 / 面试回答 / JD 方向调整；
- 检测是否处在投递后空档期，生成投递质量复盘、JD 共性整理、可复用资产补充、信息摄入边界和今天 5-20 分钟动作；
- 生成可复制给普通 LLM、Coze、Codex 或 Claude Code 的任务包；
- 生成可复制给 WorkBuddy 智能体的任务包；
- 当选择 WorkBuddy、Coze / Bot 或公众号短输入时，任务包会要求模型默认短回复，减少平台超时；
- 在浏览器本地保存简短知识库草稿。

## 边界

- 它不是聊天机器人，不会直接调用大模型；
- 它不会自动投递、自动私信 HR 或承诺面试结果；
- 它不替使用者做最终决定；
- 粘贴内容前仍然需要脱敏，本地诊断不能替代人工脱敏检查。

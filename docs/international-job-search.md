# International / Cross-market Job Search

This guide applies when the candidate and target role span different job markets, locations, hiring systems, or work-authorization contexts.

It is not the default mode for English-speaking CCC users. The language you use with CCC does not define the job market you are applying in.

This is not a legal, immigration, tax, or financial guide.

International / cross-market does not mean US-only.

CCC should be region-sensitive, not country-stereotype-driven:

```text
specific employer + role + region
>
generic country stereotypes
```

## What CCC Should Check First

CCC should not ask every question every time. It should only extract variables that can change the decision.

High-impact variables:

- target region;
- work authorization / sponsorship;
- location / remote eligibility;
- local resume convention;
- second-language communication.

These variables are independent. For example, a user can be domestic + second-language, or cross-market + native English.

## Work Authorization / Sponsorship

If a user says they may need sponsorship, CCC should treat it as an eligibility constraint, not weak candidate fit.

Useful user-facing phrasing:

```text
Work authorization:
You may need sponsorship.

What this affects:
Some roles may not be eligible even if your experience is a good match.
```

Use minimum necessary information. If clarification is necessary, prefer:

```text
Do you currently need employer sponsorship?
```

Do not ask for nationality by default, and do not ask for:

- passport numbers;
- visa document numbers;
- national ID numbers;
- social security numbers;
- scans of right-to-work documents.

CCC can help identify questions to verify, but it does not provide immigration or legal advice.

## Remote / Location / Timezone

Remote does not automatically mean the candidate can work from any country.

If remote eligibility changes the application decision, check:

- country restriction;
- timezone overlap;
- office attendance;
- relocation requirement.

Avoid saying a role is suitable for cross-market applicants just because the JD says "remote."

## Resume vs CV

CCC should not assume that CV means academic CV.

Resume / CV convention depends on target market, role, industry, and employer context, not the language used with CCC.

If a user says resume or CV, clarify based on:

- target region;
- industry;
- role type;
- academic vs non-academic context.

If the target region is unknown, mark it as unknown or ask once. Do not default to US conventions.

## Local Resume Conventions

Do not claim:

- all international resumes must be one page;
- all resumes must exclude photos;
- every region follows US resume conventions;
- every CV is academic.

Before making region-specific resume claims, verify or ask for the target market.

## Cover Letter

Do not default to writing a cover letter for every role.

First classify the requirement:

- required;
- optional;
- not requested.

If optional and application friction is already high, do not automatically add a full cover letter. A short targeted note, recruiter message, or JD patch may be enough.

## LinkedIn

CCC can help with:

- headline;
- about section;
- experience entries;
- recruiter messages;
- networking messages.

Do not assume every country, industry, or role relies heavily on LinkedIn.

Facts first. No invented achievements.

## ATS

CCC can help:

- align truthful terminology with the JD;
- use role-relevant keywords that match actual experience;
- keep formatting parseable.

CCC should not promise:

- guaranteed ATS scores;
- guaranteed ATS passes;
- keyword stuffing that changes facts.

## Language Claims

Language claims should match evidence.

Possible levels:

- native;
- bilingual;
- fluent;
- professional working proficiency;
- working proficiency;
- conversational;
- basic.

Do not upgrade working communication to fluent or native without evidence.

## Second-language Interview

Clear English is better than sophisticated English.

Do not translate a first-language answer sentence by sentence. Prefer:

- one clear point;
- 2-3 supporting points;
- short evidence;
- natural phrases;
- speakable English.

Avoid:

- long corporate scripts;
- over-polished wording that the user cannot say naturally;
- native-sounding claims without evidence.

## Employment Type

International applications may involve:

- full-time employee;
- fixed-term employee;
- contractor;
- agency / staffing;
- outsourced role;
- internship;
- part-time;
- freelance.

Clarify client brand vs actual employer when it affects risk, benefits, sponsorship, or career value.

## Notice Period / Start Date

Do not assume the user can start immediately.

Track:

- available start date;
- notice period;
- relocation timeline;
- visa or work authorization timeline.

## References / Background Checks

Offer-stage conditions may include:

- references;
- background checks;
- education verification;
- employment verification.

CCC can help organize what is confirmed and what is still conditional. It must not help fabricate references or proof documents.

## Compensation / Offer Terms

International offers may include:

- base salary;
- bonus;
- commission;
- equity;
- RSUs;
- options;
- sign-on bonus;
- pension / retirement contribution;
- health insurance;
- paid leave;
- relocation package;
- visa support.

Separate:

- guaranteed;
- conditional;
- uncertain.

Also track:

- currency;
- pay frequency;
- benefits;
- relocation cost;
- visa support;
- probation or trial period.

CCC does not provide tax advice and should not calculate take-home pay unless a reliable future tool exists.

## Region-sensitive Role Families

Do not mechanically translate job titles across markets, companies, or industries.

Example:

Chinese "运营" is not always "Operations." Depending on actual responsibilities, it may map to:

- Product Operations;
- Business Operations;
- Growth Operations;
- Marketing Operations;
- Customer Success;
- Project Coordinator;
- Program Coordinator;
- Sales Operations;
- Content Marketing;
- Community;
- another role family.

Cluster roles by:

- actual responsibilities;
- decision scope;
- stakeholders;
- tools;
- seniority;
- business context.

## Banner

```text
文件：assets/ccc-banner.png
尺寸：1280 x 640
比例：2:1
用途：README 顶部 Hero
```

视觉方向：

```text
安静
理性
可信
克制
导航感
路径感
留白
```

避免：

```text
AI 机器人
紫蓝霓虹科技风
成功人士照片
金币 / Offer / 火箭
“上岸”成功学视觉
```

推荐：

```text
米白 / 浅灰背景
黑色或深灰正文
低饱和蓝 / 橙作为单一强调色
抽象路径 / 罗盘 / 分支收束线条
```

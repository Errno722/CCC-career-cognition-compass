# Synthetic User Profile

本文件只用于 CCC 可用性测试。所有信息均为虚构，不包含真实姓名、公司、联系方式、薪资、合同、offer 或面试记录。

## 基本状态

- 测试对象：测试用户 A。
- 工作年限：3 年。
- 过往方向：内容运营 / 用户运营。
- 当前状态：Gap 8 个月，随时入职。
- 可用时间：每天约 2 小时。
- 求职目标：希望较快找到相对匹配的工作，不追求一次定位到终身方向。
- 当前困扰：信息看得很多，但不知道先投什么、怎么讲自己、怎么把项目讲清楚。

## 过往经历

- 做过内容选题、社群维护、活动执行、用户反馈整理和基础数据复盘。
- 更熟悉执行和推进类工作，不确定自己是否适合产品、项目协调或 AI 相关岗位。
- 面试时容易讲太多细节，面试官不一定能抓到重点。
- 对英文工作沟通有基础，但不应包装成接近母语或完全流利。

## 个人项目

- 做过一个 Shopify 个人项目。
- 完成过网站搭建、主题调整、商品结构、支付页面、物流政策页面和基础数据工具配置。
- 使用过 GA4、Google Search Console 和一些 AI 工具辅助整理文案、页面结构和学习资料。
- 项目没有真实销售、付费用户或增长数据。
- 项目可以证明从模糊想法推进到可运行页面的能力，但不能表述为商业成功。

## 目标方向假设

- 用户运营。
- 内容运营。
- 产品运营助理。
- 项目执行 / 项目协调。

## 不应出现的内容

- 真实姓名。
- 真实公司名。
- 真实电话或邮箱。
- 真实薪资、offer 或合同。
- 虚构销售额、转化率、用户量或商业结果。
- 把“接触 AI 工具”写成正式 AI 岗位经验。

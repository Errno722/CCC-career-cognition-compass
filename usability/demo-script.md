# CCC Demo Script

目标时长：30-60 秒。

Demo 只展示一个纵向流程：混乱输入 → 一个主线 → 继续补项目 → 项目事实卡 → 合成 JD → 简历补丁 + 面试准备动作。

## 产品定位

```text
CCC 不是直接替你写简历。它先帮你把自己说清楚，再把事实变成可以使用的求职材料。
```

## 分镜

| 画面 | 时长 | 屏幕内容 | 旁白 / 字幕 |
| --- | ---: | --- | --- |
| 1 | 5s | 用户发送一段混乱输入：Gap、运营、AI、Shopify、不知道投什么 | “不是每个人一开始都能说清楚自己要什么。” |
| 2 | 8s | CCC 输出本轮主线、暂存分支和一个小动作 | “CCC 先收束，而不是一次生成一大堆材料。” |
| 3 | 6s | 用户输入：继续补项目 | “用户可以用短标签恢复一个分支。” |
| 4 | 10s | CCC 输出 Shopify 项目事实卡：目标、个人贡献、证据、不能夸大的边界 | “先确认做过什么，再决定怎么表达。” |
| 5 | 10s | 用户发送合成产品运营 JD，CCC 判断岗位类型和 2-3 个能力重点 | “拆 JD 时先看岗位重心，而不是只看标题。” |
| 6 | 10s | CCC 输出简历补丁方向和一个面试准备动作 | “最后得到的是可修改的材料方向，以及今天能做的小事。” |

## 不展示

- 不展示完整长对话。
- 不展示开发字段、Eval、Rubric、Schema 或 Runner。
- 不展示真实简历、真实公司、真实联系方式或真实面试记录。
- 不展示终端长日志。
- 不宣称 CCC 能自动找到工作。
- 不宣称适用于所有模型。
- 不宣称平台会永久保存用户资料。

## 可用结尾

```text
如果你也被求职信息推着走，可以先从一句很乱的话开始。
```
